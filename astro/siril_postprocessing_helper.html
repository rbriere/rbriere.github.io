Siril Post Processing Helper

This MacOS shell script will create a new folder for your Siril processing with the required four sub folders, as well as a script to assist with copying the *.fit files to the ./lights folder.

You will have previously saved the script, made it executable, and modified the hard coded folders listed under the 'Variables' section to correspond to where you have your folders located.

Variable 'destinationfolder' must be the fully qualified folder where you will be copying the original *.fit files, and where you will be initializing Siril to point to.

Variable 'fitsourcefolder' must be the fully qualified folder when you keep the original files copied from your astro camera.

Note: to change the saved version of this script to be executable, from a terminal prompt, run: chmod +x “whateverYouNamedTheScriptTo.sh" (You should save the script with the .sh extension)

Note: you may have to edit the 'copyFitfiles.sh' script that is created to make sure your source (image repository) has the correct folder name. My astro camera often puts a space between the M for Messier and the number, like 'M 101_sub'.
